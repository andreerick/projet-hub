# Project Hub

Project Hub est une application personnelle destinée à centraliser la
gestion des projets et à simplifier les échanges de fichiers avec GitHub
et les outils d'IA, dans les limites des intégrations disponibles.

## Objectif de la Version 0

-   Créer et ouvrir des projets
-   Tableau de bord simple
-   Glisser-déposer de fichiers
-   Classement automatique
-   Journal des actions
-   GitHub : Commit + Push en un clic, et Pull

## Principe

L'interface doit rester simple, avec le moins de manipulations possible.
GitHub deviendra la source officielle du code et de la documentation du
projet.
