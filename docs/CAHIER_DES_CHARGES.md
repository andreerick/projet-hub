# Cahier des charges --- Project Hub v0

## But

Créer une application Windows personnelle qui centralise les projets et
simplifie leur gestion.

## Fonctions v0

1.  Créer un projet.
2.  Ouvrir un projet existant.
3.  Afficher les projets récents.
4.  Accepter le glisser-déposer de fichiers.
5.  Classer les fichiers par type.
6.  Conserver un journal des actions.
7.  Connecter un projet à un dépôt GitHub.
8.  Proposer Commit + Push en une action.
9.  Proposer Pull pour récupérer la dernière version.

## Contraintes

-   Usage personnel.
-   Windows en priorité.
-   Interface très simple.
-   Éviter les manipulations techniques inutiles.
-   Ne jamais supprimer ou écraser silencieusement un fichier
    utilisateur.
