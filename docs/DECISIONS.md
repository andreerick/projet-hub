# Décisions validées

-   Nom du projet : Project Hub.
-   Usage : personnel, non commercial.
-   Plateforme prioritaire : Windows.
-   GitHub sert de dépôt officiel du projet.
-   La Version 0 doit rester simple et fonctionnelle.
-   L'interface privilégie de gros contrôles simples : ouvrir un projet,
    déposer des fichiers, synchroniser GitHub.
-   Le projet Snooker Player pourra servir de premier projet réel pour
    tester Project Hub.
-   Les intégrations ChatGPT/Claude doivent respecter les possibilités
    techniques réellement disponibles et ne pas promettre de
    synchronisation directe lorsqu'aucune API/intégration ne le permet.
